Funções são blocos de código reaproveitáveis projetados para executar uma tarefa específica. Elas permitem que você organize seu código de maneira mais eficiente, tornando-o mais legível e fácil de manter. Em muitas linguagens de programação, funções podem receber parâmetros de entrada, realizar operações com esses parâmetros e retornar um valor como resultado.

Funções em Go são definidas usando a palavra-chave `func`, seguida pelo nome da função, uma lista de parâmetros entre parênteses e o tipo de retorno. Aqui está um exemplo básico de uma função em Go:

```go
func soma(a int, b int) int {
    return a + b
}
```
