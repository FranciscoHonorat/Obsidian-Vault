# Variáveis e tipos

Em programação, variáveis são usadas para armazenar dados que podem ser manipulados durante a execução de um programa. Cada variável possui um tipo, que define o tipo de dado que ela pode armazenar.

## Tipos de dados

Os tipos de dados podem ser classificados em diferentes categorias, como:
- Tipos primitivos: incluem inteiros, floats, booleanos e caracteres.
- Tipos compostos: incluem arrays, structs e slices.
- Tipos de referência: incluem ponteiros, maps e channels.
- Tipos personalizados: permitem que você defina seus próprios tipos de dados com base em tipos existentes.

## Declaração de variáveis

Em Go, as variáveis podem ser declaradas usando a palavra-chave `var`, seguida pelo nome da variável, o tipo e, opcionalmente, um valor inicial. Aqui está um exemplo de declaração de variáveis em Go:

```go
var idade int = 30
var nome string = "João"
```
