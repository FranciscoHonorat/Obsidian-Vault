# Tipagem estática e dinâmica

A tipagem estática e dinâmica são conceitos fundamentais em linguagens de programação que determinam como os tipos de dados são tratados durante a execução do programa.

## Tipagem Estática

A tipagem estática é um sistema em que os tipos de variáveis são verificados em tempo de compilação. Isso significa que o tipo de cada variável deve ser declarado explicitamente antes do uso, e qualquer tentativa de atribuir um valor de tipo incompatível resultará em um erro de compilação. Linguagens com tipagem estática incluem C, C++, Java e Go.

## Tipagem Dinâmica

A tipagem dinâmica, por outro lado, é um sistema em que os tipos de variáveis são verificados em tempo de execução. Isso permite que as variáveis possam receber valores de diferentes tipos ao longo da execução do programa, proporcionando maior flexibilidade. Linguagens com tipagem dinâmica incluem Python, JavaScript e Ruby.
